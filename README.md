# GPT Best - AI Platform

A futuristic AI platform landing page built with React, TypeScript, and Tailwind CSS.

## Features

- 🚀 Modern, responsive design
- 💬 Interactive AI chat preview
- 🧠 Learning-focused content
- ⚡ Fast and optimized
- 🎨 Beautiful gradient effects

## Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- React Scripts

## Getting Started

### Prerequisites

- Node.js (v14+)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm start
```

Runs the app in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### Build

```bash
npm run build
```

Builds the app for production to the `build` folder.
